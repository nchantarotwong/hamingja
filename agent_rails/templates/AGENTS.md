# Agent instructions

This file is read by coding agents working in this repository
(Codex natively, Claude Code via a `CLAUDE.md` that points here).
It carries the **soft workflow rails** for this project: how to debug,
when to escalate, what to do when the user asks the agent to stop.

These instructions are **advisory**. They are not a kill switch. The
deterministic safety layer — repetition / oscillation / error-streak
tripwires that can actually block a tool call — lives in the
[`agent-rails`](https://github.com/) package itself and runs as a hook,
outside the agent's judgment. Nothing in this file blocks anything; the
agent is expected to follow it because the rules below are how good
engineering work gets done, not because a hook will punish it.

Generated by `agent-rails init`. Edit freely; re-run `agent-rails init
--force` to regenerate from upstream profiles.
